# OS-Assignment2 

## Description  
An assignment for the OS that covers basic process creation ,process management
,and linker and loader roles. IT includes C programming examples and Linux commands 

## Installation  
Requiers GCC on Ubuntu Linux : 
sudo apt install gcc 
 
## Usage 
compile and run the programs: 
gcc process_creation.c -o process_creation 
./process_creation

gcc file1.c  file2.c -o output_program 
./output_program 

gcc simple_program.c -o simple_program 
./simple_program 
ldd simple_program
 
## Project Structure 
1. process_creation.c -- demonstrates process creation using fork() 
2. file1.c -- contains helle function
3. file2.c -- declares and calls hello function 
4. simple_program.c -- demonstrates a simple C program 
5. Makefile -- contains comlilation instructions 
6. answers.txt -- contains assignment answers 
7. LICENSE - license text
